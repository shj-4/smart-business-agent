# وكيل الأعمال الذكي (BizMate)

مساعد Telegram شخصي/لمنشأة صغيرة: يدوّن المعاملات والمهام والطلبيات بالعربية
(بما فيها اللهجات الفلسطينية)، يجيب عن الأسئلة (إنفاق/إيرادات/رصيد شخص/
مهام...)، يرسل تقارير ومخططات ورسمًا بيانيًا، مع تشفير الحقول الحساسة
ومشاركة مساحة عمل وأدوات تصدير ونسخ احتياطي.

## المزايا

- **تسجيل ذكي**: نص حر ("300 شيكل لمحمد مقابل مواد"، "ذكرني كل أسبوع أتصل
  بالمورد") → تفكيك بالـ AI إلى معاملة/مهمة/طلبية/ملاحظة مع تأكيد قبل الحفظ.
- **استعلامات**: نفقات/إيرادات/رصيد مع شخص/مقارنة فترات/المهام المتأخرة.
- **ملفات وسائط**: فواتير من الصور (تحليل إيصال)، نسخ صوتي، تسجيل صوتي.
- **أزرار وقوائم**: قوائم Inline عربية (تسجيل، تقارير، مهام، أدوات، إعدادات)
  مع واجهة إنكليزية جزئية قابلة للتوسيع.
- **آخر العمليات + بحث**: تصفّح (صفحات) وتعديل/حذف مباشر، وبحث نصي.
- **تقارير دورية / خرائط / تصدير Excel** وجدولة مهام متكررة وتذكيرات.
- **مساحة مشتركة**: مورّد/عميل بين الأعضاء بأدوار (مرتكز/عضو).
- **ديون وحدود وفواتير**: `/debts` رصيد مدين/دائن لكل شخص، `/credit` حدود
  ائتمانية مع تنبيهات، فواتير آجلة تُرحَّل تلقائيًا وتُسدَّد عبر `/invoices`.
- **البونس والمكافآت (#39)**: `/bonus` واجهة موحّدة — تسجيل بونس
  (منح/استلام)، فعاليات ترويجية بميزانية ومدة، مكافآت موظفين دورية مع
  سقف شهري وتنبيه، ونقاط ولاء عملاء (تراكم + استبدال).
- **ميزانيات بالنطاق**: ميزانية تصنيف لشهر/فترة (12 شهرًا/كل الوقت) مع تنبيهات
  تجاوز، ودورة طلبيات كاملة (open → paid/done) عبر `/orders`، وضريبة VAT.
- **صحة واستخدام**: `/health` فحص النظام (قاعدة/هجرات/بيئة/تشفير/حجم) عند
  الطلب وعند الإقلاع، و`/stats` إحصائيات الاستخدام.
- **تنبؤ وتحليل**: `/forecast` توقع مصاريف/إيرادات الأشهر القادمة
  (انحدار خطي إرشادي)، و`/deviation` كشف انحراف الشهر الحالي عن متوسط
  آخر 3 أشهر مع تنبيه يومي تلقائي.
- **تصدير Excel وPDF**: `/export [today|week|month]` ملف Excel موحّد،
  و`/export pdf` ملف PDF واحد بكل السجلات (reportlab + خط عربي).
- **أمان**: تشفير الوصف/المبالغ (cryptography)، حدّ للرسائل (مستخدم + كلي)،
  حارس حقن برومبت، سجل تدقيق، إخفاء الأسرار.
  (> ملاحظة تخزين: الحقول `description` و `raw_message` و `amount` تُشفَّر عند
  ضبط `ENCRYPTION_KEY`، لكن حقل **`person`** (مورد/عميل) يُخزَّن نصًا صريحًا
  — مقصود ليتيح البحث المطابق بـ LIKE.)

## البداية

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# ثم:
pip install -r requirements.txt
python -m alembic upgrade head   # إنشاء قاعدة SQLite محليًا
python bot.py                    # تشغيل البوت
uvicorn app.main:app --port 8000 # (اختياري) واجهة API
```

## الإعداد (.env)

انقل `.env.example` إلى `.env` وعبّئ:
`TELEGRAM_BOT_TOKEN` و `GEMINI_API_KEY` إلزاميان؛
`ENCRYPTION_KEY` للتشفير (اختياري: بدونه يُخزَّن النص صريحًا في التطوير).
الحقول المشفّرة عند ضبط المفتاح: `description` و `raw_message` و `amount`.
ملاحظة: حقل **`person`** (المورد/العميل) يُخزَّن نصًا صريحًا دائمًا — مقصود
لتمكين البحث المطابق، لكنه يعني أن أسماء الأشخاص غير محمية بالتشفير.

| متغير | الوصف |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Bot token من @BotFather |
| `GEMINI_API_KEY` | مفتاح Google AI Studio |
| `ENCRYPTION_KEY` | مفتاح base64 (32 بايت) لتشفير الحقول |
| `DATABASE_URL` | اختياري — MySQL بدل SQLite |
| `ADMIN_USER_IDS` | أرقام أدمن (لفواصل) لأوامر `/admin_stats` |
| `APP_ENV` | `development` / `staging` / `production` (SQLite منفصل) |
| `LOG_FORMAT` | `text` أو `json` (سجلات منظمة) |
| `SENTRY_DSN` | اختياري — يُفعَّل عند تعبئته |

## قاعدة البيانات والنسخ الاحتياطي

- هجرات Alembic في `migrations/`؛ `alembic upgrade head` يطبّقها.
- إعادة إنشاء قاعدة من الهجرات خطوة بخطوة (للبيئات المتقدمة):
  `python scripts/reapply_migrations.py --yes` — مع `--dry-run` للاستعراض.
- نسخ احتياطي يومي تلقائي (احتفاظ بـ 7 نسخ) + يدوي:
  `python scripts/backup_db.py` — تُخزَّن في `data/backups/`.

## الاختبارات والتغطية

```bash
python -m pytest                      # الوحدة + E2E خفيفة (بلا شبكة)
python -m pytest -m integration       # اختبارات تتصل بـ Gemini (يدويًا)
```

تقرير التغطية يُطبع تلقائيًا (`--cov=app --cov=bot`)؛ تهيئة Ruff في
`pyproject.toml` مع `.pre-commit-config.yaml`.

## البنية

- `app/` — نماذج/CRUD/تشفير/ذكاء اصطناعي/تقارير/تصدير/تدقيق/نسخ احتياطي،
  و`app/database/migration_replay.py` لإعادة تطبيق الهجرات.
- `bot/` — أزرار القوائم، المحادثة، تذكيرات، حدود، ترجمة،
  و`bot/diagnostics.py` لفحوصات الصحة.
- `prompts/` — نصوص توجيه الـ AI في ملفات مستقلة (تُحرَّر بلا كود).
- `migrations/` — هجرات Alembic.
- `scripts/` — أدوات سطر أمر: نسخ احتياطي، إعادة تطبيق الهجرات.
